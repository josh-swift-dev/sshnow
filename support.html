SSH Now Support

Need help with SSH Now? Here are the most common setup and connection steps.

Getting Started

  1. Open SSH Now and tap Add Server.
  2. Enter the hostname or IP address, SSH port, and username.
  3. Choose password or private-key authentication and provide the appropriate credential.
  4. Save the connection and tap the saved server to connect.
  5. On a first connection, review the server's host-key fingerprint before accepting it.

Private Keys

SSH Now supports unencrypted OpenSSH Ed25519 and RSA private keys. Passphrase-protected or encrypted private keys are not currently supported.

Connection Problems

Verify the hostname or IP address, SSH port, username, credentials, network connection, and that the remote SSH service is running and reachable.

Host-Key Warning

If SSH Now reports that a known host key changed, verify the change with the server administrator before accepting it.
