SSH Now Support

Need help with SSH Now? This page covers common questions, SSH Now Pro purchases, and ways to contact support.

SSH Now Pro

SSH Now is available as a free download with an optional SSH Now Pro upgrade.

SSH Now Pro is a one-time $1.99 in-app purchase.

There is no monthly or yearly subscription for the Pro lifetime unlock.

Purchasing SSH Now Pro

Open SSH Now and select the option to unlock SSH Now Pro. The purchase is processed securely through Apple's App Store.

The price displayed by the App Store at the time of purchase is the price that applies to your account and region.

Restore Purchases

If you previously purchased SSH Now Pro and reinstall the app or move to another compatible device, use the Restore Purchases option inside SSH Now.

Make sure you are signed into the App Store using the Apple Account that originally purchased SSH Now Pro.

Purchase Not Unlocking

If your purchase completed but SSH Now Pro does not appear unlocked:

  1. Make sure your device has an internet connection.
  2. Confirm you are signed into the correct Apple Account.
  3. Open SSH Now and select Restore Purchases.
  4. Close and reopen SSH Now if necessary.

If the problem continues, contact support using the email address below.

SSH Connection Problems

If SSH Now cannot connect to a server, verify:

  • The hostname or IP address is correct.
  • The SSH port is correct.
  • The username and authentication information are correct.
  • The SSH server is running and reachable from your current network.
  • A firewall or network security rule is not blocking the connection.

SSH Now cannot change the configuration of a remote SSH server, firewall, router, or hosting provider.

Billing and Refunds

Payments for SSH Now Pro are processed by Apple through the App Store. Billing, purchase history, and refund requests are handled through Apple's App Store services.
